### Framing the Infinity-mode limit

Raised during discussion: because `GroupHistoryTree` has no pruning in v1 (per the full-history
design — "grow all forks for max debugging, prune later"), the tree-derived horizon under
`Infinity` still resolves to the root epoch. It is therefore a **correctness** bound, not a
memory bound, in that mode.

| Option | Description | Selected |
|--------|-------------|----------|
| Ship it as correctness; state the limit plainly | Fix the false class doc; record the Infinity limit as an accepted consequence | ✓ |
| Also make it self-bounding independent of the tree | Bounded in every mode, but risks pruning what a branch could name | |
| Treat tree pruning as in-scope here | Closes it properly; a new convergence-core capability, its own phase | |

**User's choice:** Ship it as correctness; state the limit plainly.
