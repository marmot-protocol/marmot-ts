<objective>
Build the shared, proof-class-agnostic `MarmotAuthorizationProof` envelope primitive in `src/core/authorization-proof.ts`
(D-03): a strict 104-byte encode/decode (AUTHZ-01), bigint-safe `created_at` range enforcement on decode and before
signing (AUTHZ-02; D-06, D-07, D-08), x-only secp256k1 signer-pubkey validation (AUTHZ-03), NIP-01 event-id
reconstruction from a plain `{ kind, tags, content }` template plus BIP-340 verification (AUTHZ-04; D-01, D-02), and a
produce path that signs through `Pick<EventSigner, "signEvent">` and rejects any external-signer substitution field by
field (AUTHZ-05; D-09, D-10, D-11). Every rejection is a typed `AuthorizationProofError` with a one-per-step `reason`
(D-04, D-05). The spec signing vector must reproduce byte-for-byte through this generic primitive (D-13). The new symbols
are exported through the core barrel and the root exports snapshot is refreshed (D-12).

Purpose: this primitive is the cheapest correctness gate of milestone v2.0 and a hard blocker for Phase 7 (the `0x8009`
proof class) and Phase 8 (`validateCommitLegality` maps `reason`). It has no I/O, no MLS dependency, and no knowledge of
any particular proof class.

Output: one new source file, one new colocated test file, a one-line barrel addition, and a regenerated exports snapshot.
Out of scope (Phase 7): the `0x8009` proof-class module, KeyPackage/leaf wiring, and any edit to the legacy
`src/core/account-identity-proof.ts` (`0xf2f1`).
