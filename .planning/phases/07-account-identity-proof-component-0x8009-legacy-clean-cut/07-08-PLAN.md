<objective>
Handle legacy local KeyPackage state (D-09). Flag every stored KeyPackage whose leaf lacks a valid `0x8009` proof as
`nonCurrent`, and make `ensurePublished` publish a fresh current package instead of reusing it, without deleting anything
or sending a kind-5. Then publish the release surface of the clean cut (D-11): a major changeset and a short docs
migration section. Sweep the remaining docs and READMEs so none tells users to supply a separate proof signer or presents
the v1 extension as current (CUT-01).

Purpose: after plan 07-06, an app that stored a v1.0 KeyPackage would otherwise keep advertising a package that no v2
peer accepts. The docs and changeset make the breaking change and the migration path explicit.

Output: a `nonCurrent` flag on listings, a filtered `ensurePublished`, focused tests, one changeset, and updated docs.
</objective>
