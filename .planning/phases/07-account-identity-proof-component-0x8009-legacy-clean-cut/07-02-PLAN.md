<objective>
Remove the separate proof-signer option from the whole client API and prove every client-built leaf with the client's
existing `signer: EventSigner` (D-01). Thread a `signer` option into core `generateKeyPackage` so the client can pass it.
Delete the raw-key proof-signer helpers from tests and from the OpenTUI example (D-04), and add a deterministic,
pubkey-ordered test-account helper that the parallel wave-2 plans use to pass real signers everywhere (D-02).

Purpose: this is the API-surface half of the cut. It is wire-neutral: `generateKeyPackage` still emits the legacy leaf
format through the existing module until plan 07-06 swaps the leaf format and the verifier seams atomically. Keeping
this plan wire-neutral keeps the suite green between plans.

Output: a narrower client option surface, one new core option, two deleted helper files, one new test helper plus its
test, and ten test files plus the example updated.
</objective>
