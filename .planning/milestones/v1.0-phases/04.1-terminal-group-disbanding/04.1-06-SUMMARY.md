## Decisions Made

- Notification delivery is recorded durably before callbacks, so listener failures can neither roll back terminalization nor cause restart duplicates.
- The engine owns the authoritative repeat gate; the manager adds an earlier routing optimization so untrusted traffic never allocates crypto or convergence work.
- `Unrecoverable` is intentionally not included in terminal routing checks because it remains a repairable convergence state.
