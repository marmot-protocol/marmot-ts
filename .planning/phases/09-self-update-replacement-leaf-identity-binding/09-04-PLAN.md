<objective>
Ratify UPD-02 and UPD-03 with named regression tests and add no new validator code, then refresh the root exports
snapshot and prove the whole suite is green with every Phase 9 gate active.

Purpose: both requirements are already enforced by Phase 8's changed-leaf validator — UPD-02 because step 11
reconstructs the signing template from the leaf's own signature key, so a proof bound to a different key fails
verification; UPD-03 because stripping the dictionary changes the leaf, which changes its signature, so the tree diff
always surfaces it, and because removal via `AppDataUpdate` is separately refused by the leaf-only guard. Duplicating
either as a standalone check would create two places to keep in sync — the trap Phase 7 D-12 warned about.
Output: named UPD-02 and UPD-03 test blocks, an updated exports snapshot, and a green full suite.
</objective>
