<objective>
Close the 30443 KeyPackage inbound boundary on all three fronts at once: verify the outer
event, enforce `d`/`i`/`mls_protocol_version` cardinality, and reject over-long/expired
Lifetimes — across both 30443 consumption paths (`KeyPackageManager.track()` →
`KeyPackageStore.addPublished()` and the store-bypassing `createInviteIntent()`), plus the
soft eligibility evaluator.

Purpose: Finish SEC-01 for the 30443 path, close WIRE-01 inbound, and close WIRE-02 for
the KeyPackage tags. This is the heaviest boundary because two independent code paths
consume 30443 events and both must apply the same checks.
Output: an inbound Lifetime read helper, an eligibility Lifetime reason, and verify +
cardinality + lifetime gates on `track()` and `createInviteIntent`, with a `rejected`
event on KeyPackageManager.
</objective>

## Trust Boundaries

| Boundary                              | Description                                                                                     |
| ------------------------------------- | ----------------------------------------------------------------------------------------------- |
| relay/app → KeyPackageManager.track() | Untrusted 30443 KeyPackage events fetched from relays enter here for the passive-discovery path |
| app → createInviteIntent()            | A raw keyPackageEvent is turned into an Add proposal, bypassing KeyPackageStore entirely        |
| peer KeyPackage → group Add           | An over-long-lived or malformed-tag KeyPackage could be admitted to a group                     |
